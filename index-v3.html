SYSTEMS — เทรดหลายมุมมองพร้อมกัน

แต่ละระบบมีวิธีคิดคนละแบบและรันแยกอิสระ — กระจายความเสี่ยงของ "วิธีการ" ไม่ใช่แค่กระจายไม้

SYS_A

กลยุทธ์หลายชั้น

บอทหลายตัวบนบัญชีเดียว รันกลยุทธ์เชิงกลไกกว่า 30 แบบ (EMA · Order Block · Liquidity Sweep · Fibonacci) พร้อมชั้นจัดการความเสี่ยงกลาง

guards: correlation_cap · news_filter · equity_curve · safety_lock
SYS_B

5 ทีม AI แข่งกัน

ทีม LLM 5 ทีม (Gemini · Groq · OpenRouter · Mistral · Cohere) มีธรรมนูญของตัวเอง ลูกทีม 6 ตำแหน่งให้ความเห็น หัวหน้าทีมตัดสินใจ

gates: critic → RR_gate → WR_throttle → consensus
SYS_7

ชั้นเกม RPG

ห่อกลยุทธ์เป็น "อาวุธ" ในเกม — แต่ละคู่เงินคือด่าน มี HP/EXP/แรงค์ และห้องแล็บทดสอบอาวุธใหม่แบบกระดาษ

weapons: SWORD · SPEAR · RUNE · BOW · CHARGE
[ 02 ]

PRINCIPLES — เบา โปร่งใส ดูแลตัวเองได้

ทุกการตัดสินใจออกแบบให้ตรวจสอบย้อนหลังได้ และไม่มีชิ้นส่วนไหนที่พังแล้วเงียบ

COST_ZERO
ไม่มีค่า API รายเดือน — MetaTrader 5 Python + ไฟล์ JSON ในเครื่อง + Telegram (ฟรีทั้งหมด) ไม่มีการเรียก API เสียเงินเข้า loop เทรด
PROVE_FIRST
ทุกการแก้กลยุทธ์ผ่าน bar-walk backtest กับแท่งเทียนจริง ก่อนเสมอ · ไอเดียใหม่ทดสอบแบบกระดาษจนพิสูจน์ตัวเองก่อนเข้าโค้ดจริง
SELF_WATCH
เอเจนต์ 7 ตัวรันเป็นรอบ · วิเคราะห์แพทเทิร์น / เฝ้า process·tick·SL-TP / แก้บั๊ก / เฝ้าทีม AI / ค้นเทคนิค / รีเฟรชความจำ / คัดกรองไอเดีย + dead-man's-switch
LAYERED_GUARD
ก่อนไม้เปิด ต้องผ่าน correlation cap · news blackout · RR gate ทางคณิตศาสตร์ · WR throttle · safety-lock บังคับด้วย hook ระดับเครื่องมือ
BACKUP
มิเรอร์ทั้งโปรเจกต์ + สแนปช็อตไฟล์สถานะรายวันไปไดรฟ์แยก · มีตัวเฝ้าความสดของแบ็กอัพเอง (แจ้งเตือนถ้าเกิน 48 ชม.)
